## 1. レイヤー構成

Backendは以下のレイヤーで構成する。

```text
Frontend
   ↓ HTTP Request
Controller
   ↓
Service
   ↓
DAO
   ↓
Oracle Database
```

各レイヤーでは、役割を分離して処理する。

## 2. Controller

ControllerはFrontendからのHTTPリクエストを受け付ける。

主な役割は以下とする。

- URLおよびHTTP Methodに応じた処理の受付
- Path Parameterの取得
- Request Bodyの受け取り
- Bean Validationの実行
- Serviceの呼び出し
- 処理結果のレスポンス返却

小説情報の処理は`NovelController`で受け付ける。

Controllerでは業務処理やDatabaseアクセスを行わず、Serviceへ処理を委譲する。

```text
HTTP Request
   ↓
NovelController
   ↓
NovelService
```

## 3. Service

Serviceは小説管理に関する処理を実行する。

主な役割は以下とする。

- DAOの呼び出し
- 小説存在チェック
- タイトル重複チェック
- Request DTOからEntityへのデータ設定
- EntityからResponse DTOへの変換
- 文字列データの整形
- 登録、更新、削除時のトランザクション管理

小説登録・更新時は、タイトルの前後空白を除去する。

作者およびメモは、前後空白を除去した結果が空文字の場合、nullとして扱う。

## 4. DAO

DAOはDomaを利用してOracle Databaseへアクセスする。

`NovelDao`では以下のDatabase操作を行う。

| 処理 | メソッド |
|---|---|
| 小説一覧取得 | `selectAll` |
| 小説詳細取得 | `selectById` |
| タイトル存在チェック | `existsByTitle` |
| 更新時タイトル重複チェック | `existsByTitleAndNovelIdNot` |
| 小説登録 | `insert` |
| 小説更新 | `update` |
| 小説削除 | `delete` |

小説登録時はnull項目をINSERT対象外とし、Database側にDEFAULT値が定義されている項目についてはその値を利用する。

## 5. DTO

APIで利用するデータはDTOとして定義する。

### 5.1 NovelRequest

小説登録および更新時にFrontendから受け取るデータを保持する。

入力値のValidationもNovelRequestに対して実行する。

### 5.2 NovelResponse

Frontendへ返却する小説情報を保持する。

Database用のEntityを直接APIレスポンスとして返さず、ServiceでNovelResponseへ変換する。

### 5.3 ErrorResponse

API処理でエラーが発生した場合のレスポンス情報を保持する。

## 6. Entity

`Novel`はNOVELSテーブルに対応するEntityとする。

DAOによるDatabaseアクセスではNovelを利用する。

EntityはDatabaseとのデータ受け渡しに使用し、Frontendとの直接的なデータ受け渡しには使用しない。

## 7. 処理フロー

### 7.1 一覧・詳細取得

```text
Frontend
   ↓ GET
NovelController
   ↓
NovelService
   ↓
NovelDao
   ↓ SELECT
Oracle Database
   ↓
Novel
   ↓
NovelService
   ↓ NovelResponseへ変換
NovelController
   ↓
Frontend
```

### 7.2 登録

```text
Frontend
   ↓ POST / NovelRequest
NovelController
   ↓ Validation
NovelService
   ↓
タイトル重複チェック
   ↓
Novel生成
   ↓
NovelDao
   ↓ INSERT
Oracle Database
   ↓
NovelResponseへ変換
   ↓
Frontend
```

### 7.3 更新

```text
Frontend
   ↓ PUT / NovelRequest
NovelController
   ↓ Validation
NovelService
   ↓
対象小説取得
   ↓
タイトル重複チェック
   ↓
Novel更新
   ↓
NovelDao
   ↓ UPDATE
Oracle Database
   ↓
NovelResponseへ変換
   ↓
Frontend
```

### 7.4 削除

```text
Frontend
   ↓ DELETE
NovelController
   ↓
NovelService
   ↓
対象小説取得
   ↓
NovelDao
   ↓ DELETE
Oracle Database
```
