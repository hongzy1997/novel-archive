## 1. 機能要件

Novel Archiveでは、小説情報を管理するため、以下の機能を提供する。

| No. | 機能 | 概要 |
|---|---|---|
| 1 | 小説一覧表示 | 登録されている小説を一覧表示する |
| 2 | 小説詳細表示 | 選択した小説の詳細情報を表示する |
| 3 | 小説登録 | 新しい小説情報を登録する |
| 4 | 小説編集 | 登録済みの小説情報を編集する |
| 5 | 小説削除 | 登録済みの小説情報を削除する |
| 6 | タイトル検索 | 小説一覧をタイトルで絞り込む |
| 7 | 表示言語切替 | 画面表示を日本語・中国語で切り替える |

## 2. 管理項目

小説情報として以下の項目を管理する。

| 項目 | 内容 |
|---|---|
| タイトル | 小説のタイトル |
| 作者 | 小説の作者 |
| 読書状態 | 未読、読書中、読了、中断を管理する |
| 評価 | 小説に対する1～10の評価 |
| メモ | 感想や補足情報 |

## 3. 業務ルール

- タイトルは必須とする。
- 作者は任意入力とする。
- 同一タイトルの小説は重複して登録できない。
- 読書状態は未読、読書中、読了、中断のいずれかとする。
- 未読の場合は評価を設定しない。
- 未読以外の場合は1～10の評価を必須とする。
- メモは任意入力とする。
