## 1. パッケージ構成

BackendのJavaソースは以下の構成とする。

```text
com.hongzy.novelarchive
├─ BackendApplication.java
├─ controller
│  └─ NovelController.java
├─ service
│  └─ NovelService.java
├─ dao
│  └─ NovelDao.java
├─ dto
│  ├─ NovelRequest.java
│  ├─ NovelResponse.java
│  └─ ErrorResponse.java
├─ entity
│  └─ Novel.java
├─ exception
│  ├─ GlobalExceptionHandler.java
│  ├─ NovelNotFoundException.java
│  └─ NovelAlreadyExistsException.java
└─ validation
   ├─ ValidRating.java
   └─ RatingValidator.java
```

## 2. パッケージの役割

| パッケージ | 役割 |
|---|---|
| controller | HTTPリクエストを受け付け、Serviceを呼び出してレスポンスを返す |
| service | 小説管理に関する処理を実行する |
| dao | Domaを利用してDatabaseへアクセスする |
| dto | APIのリクエスト・レスポンスデータを定義する |
| entity | NOVELSテーブルに対応するデータを定義する |
| exception | アプリケーションで発生する例外および共通例外処理を管理する |
| validation | 小説情報固有の入力チェックを定義する |

## 3. クラス一覧

### 3.1 Controller

| クラス | 役割 |
|---|---|
| NovelController | 小説一覧取得、詳細取得、登録、更新、削除のREST APIを提供する |

### 3.2 Service

| クラス | 役割 |
|---|---|
| NovelService | 小説情報の取得、登録、更新、削除に関する処理を行う |

### 3.3 DAO

| クラス | 役割 |
|---|---|
| NovelDao | NOVELSテーブルに対するDatabaseアクセスを行う |

### 3.4 DTO

| クラス | 役割 |
|---|---|
| NovelRequest | 小説登録・更新時のリクエストデータを保持する |
| NovelResponse | Frontendへ返却する小説情報を保持する |
| ErrorResponse | APIエラー発生時のレスポンス情報を保持する |

### 3.5 Entity

| クラス | 役割 |
|---|---|
| Novel | NOVELSテーブルに対応するEntity |

### 3.6 Exception

| クラス | 役割 |
|---|---|
| GlobalExceptionHandler | APIで発生した例外を共通的に処理する |
| NovelNotFoundException | 指定した小説が存在しない場合に使用する |
| NovelAlreadyExistsException | 同一タイトルの小説が既に存在する場合に使用する |

### 3.7 Validation

| クラス | 役割 |
|---|---|
| ValidRating | 評価に対する独自Validationを指定するアノテーション |
| RatingValidator | 読書状態と評価の組み合わせをチェックする |

## 4. 基本的な依存関係

小説情報を処理する基本的な依存関係は以下とする。

```text
NovelController
      ↓
NovelService
      ↓
NovelDao
      ↓
Oracle Database
```

APIで利用するデータは、用途に応じてDTOとEntityを分離する。

```text
Frontend
   ↓
NovelRequest
   ↓
NovelController
   ↓
NovelService
   ↓
Novel
   ↓
NovelDao
   ↓
Database

Database
   ↓
Novel
   ↓
NovelService
   ↓
NovelResponse
   ↓
Frontend
```
