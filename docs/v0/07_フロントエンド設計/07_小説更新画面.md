# 小説更新画面

## 画面概要

登録済みの小説情報を更新する画面。

主な機能：

- 現在の小説情報を初期表示
- 小説情報の編集
- 入力値チェック
- 小説更新APIの実行
- 小説詳細画面への遷移
- 日本語 / 中文切替

画面ID：

```text
F004
```

URL：

```text
/novels/:novelId/edit
```

## 初期表示

URLから `novelId` を取得し、
対象小説の詳細取得APIを呼び出す。

```text
/novels/1/edit
    ↓
novelId = 1
    ↓
GET /api/novels/1
    ↓
現在の小説情報を取得
    ↓
入力項目の初期値として設定
```

初期値：

```text
title
→ 現在のタイトル

author
→ 現在の作者

readingStatus
→ 現在の読書状態

rating
→ 現在の評価

memo
→ 現在のメモ
```

登録画面とは異なり、
新規用の初期値は使用しない。

---

## 入力項目

入力項目は小説登録画面と同じとする。

| 項目 | 入力形式 | API項目 | 必須 |
|---|---|---|---|
| タイトル | Text | `title` | ○ |
| 作者 | Text | `author` | ○ |
| 読書状態 | Select | `readingStatus` | ○ |
| 評価 | Star Rating | `rating` | ○ |
| メモ | Textarea | `memo` | - |

---

## 読書状態

現在の `readingStatus` を初期選択値として表示する。

例：

```text
readingStatus = 2

↓ 初期表示

読了
```

ユーザーは以下から変更できる。

| API値 | 日本語 | 中文 |
|---:|---|---|
| 0 | 未読 | 未读 |
| 1 | 読書中 | 阅读中 |
| 2 | 読了 | 已读 |
| 3 | 中断 | 中断 |

---

## 評価

現在の `rating` を星表示へ変換して初期表示する。

例：

```text
rating = 9
    ↓
4.5
    ↓
★★★★½
```

ユーザーは0.5刻みで評価を変更できる。

API送信時は `1～10` の整数へ変換する。

```text
表示星数 × 2
    ↓
rating
```

---

## 入力値チェック

Validationルールは小説登録画面と同じとする。

| 項目 | チェック内容 |
|---|---|
| タイトル | 必須 |
| 作者 | 必須 |
| 読書状態 | 必須、0～3 |
| 評価 | 必須、1～10 |
| メモ | 任意 |

入力エラーがある場合はAPIを呼び出さず、
対象項目付近にエラーメッセージを表示する。

---

## 更新処理

更新ボタン押下時、
入力内容からRequestを作成する。

例：

```json
{
  "title": "全職高手",
  "author": "蝴蝶藍",
  "readingStatus": 2,
  "rating": 10,
  "memo": "四刷予定"
}
```

更新API：

```text
PUT /api/novels/{novelId}
```

処理フロー：

```text
更新ボタン
    ↓
Frontend Validation
    ↓
Request作成
    ↓
PUT API
    ↓
Backend Validation
    ↓
DB更新
    ↓
更新成功
    ↓
小説詳細画面
```

更新成功後は対象小説の詳細画面へ遷移する。

```text
/novels/{novelId}
```

---

## キャンセル

キャンセルボタン押下時は更新処理を行わず、
対象小説の詳細画面へ戻る。

```text
キャンセル
    ↓
/novels/{novelId}
```

---

## 画面状態

### Loading

更新対象データ取得中：

```text
読込中...
```

### Not Found

指定した `novelId` の小説が存在しない場合：

```text
小説が見つかりません。
```

### Validation Error

入力内容に問題がある場合、
対象項目付近にエラーメッセージを表示する。

### 更新中

更新API実行中は更新ボタンを無効化し、
二重更新を防止する。

### API Error

更新処理に失敗した場合：

```text
小説の更新に失敗しました。
```

入力済み内容は保持する。

---

## 言語切替

固定文言は日本語 / 中文の切替に対応する。

入力中の値は言語切替によって変更しない。

| 日本語 | 中文 |
|---|---|
| 小説更新 | 编辑小说 |
| タイトル | 标题 |
| 作者 | 作者 |
| 読書状態 | 阅读状态 |
| 評価 | 评分 |
| メモ | 备注 |
| 更新 | 更新 |
| キャンセル | 取消 |

---

## ポイント

- URLの `novelId` から更新対象を取得する
- 現在のDB値を入力項目の初期値として表示する
- 入力項目とValidationは登録画面と共通とする
- 読書状態・評価も現在値を初期表示する
- API通信中は二重更新を防止する
- 更新失敗時は入力内容を保持する
- 更新成功後は対象小説の詳細画面へ戻る
