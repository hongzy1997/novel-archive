## 1. 概要

Novel Archiveは、Frontend、Backend、Databaseを分離した構成とする。

各アプリケーションおよびDatabaseはDockerコンテナとして実行し、
Docker Composeによって一括管理する。

## 3. Backend

`backend` 配下では、Spring BootによるREST APIを管理する。

主な役割は以下とする。

- 小説情報に対するCRUD処理
- リクエストのバリデーション
- 業務処理
- Oracle Databaseへのアクセス
- トランザクション管理
- 例外処理


## 4. Frontend

`frontend` 配下では、ReactによるWeb画面を管理する。

主な役割は以下とする。

- 小説一覧表示
- 小説詳細表示
- 小説登録
- 小説更新
- 小説削除
- Backend REST APIとの通信

BuildしたReactアプリケーションはnginxから配信する。


## 5. Database

DatabaseにはOracle Databaseを使用する。

テーブル、シーケンス、トリガーなどのDBオブジェクト定義および
初期データ登録SQLはBackendのresources配下で管理する。

Oracle Databaseの初回起動時には、
初期化スクリプトから必要なDBユーザーおよびDBオブジェクトを作成する。


## 6. Docker

Frontend、Backend、Oracle DatabaseはDockerコンテナとして実行する。

`compose.yml` に各コンテナの構成を定義し、
Docker Composeによってシステム全体を一括起動する。

環境依存の設定値は `.env` で管理し、
`.env.example` を設定例としてGitで管理する。

Oracle DatabaseのデータはDocker Volumeを利用して永続化する。
