## 1. 環境変数概要

Docker環境では、Database接続に使用するユーザー名やパスワードを環境変数で管理する。

Repositoryには設定例として`.env.example`を配置し、実際の値は`.env`に設定する。

```text
.env.example
   ↓ コピー
.env
   ↓
Docker Compose
   ↓
Oracle / Backend
```

`.env`はGit管理対象外とする。

## 2. .env

Docker Composeで使用する環境変数は以下とする。

| 環境変数 | 用途 |
|---|---|
| ORACLE_PASSWORD | Oracle管理者パスワード |
| DB_USERNAME | Novel Archive用DBユーザー名 |
| DB_PASSWORD | Novel Archive用DBパスワード |

設定例は以下とする。

```env
ORACLE_PASSWORD=your_oracle_password
DB_USERNAME=NOVEL_ARCHIVE
DB_PASSWORD=your_db_password
```

実際のパスワードは`.env.example`には記載しない。

## 3. Oracle Container

Oracle Containerでは以下の環境変数を使用する。

| 環境変数 | 設定元 | 用途 |
|---|---|---|
| ORACLE_PWD | `ORACLE_PASSWORD` | Oracle管理者パスワード |
| DB_USERNAME | `DB_USERNAME` | Application用DBユーザー作成・接続 |
| DB_PASSWORD | `DB_PASSWORD` | Application用DBユーザーのパスワード |
| NLS_LANG | compose.yml固定値 | 日本語・中国語を扱う文字コード設定 |

Docker Composeでは以下のように設定する。

```yaml
environment:
  ORACLE_PWD: ${ORACLE_PASSWORD}
  DB_USERNAME: ${DB_USERNAME}
  DB_PASSWORD: ${DB_PASSWORD}
  NLS_LANG: AMERICAN_AMERICA.AL32UTF8
```

`DB_USERNAME`および`DB_PASSWORD`はDatabase初期化Scriptでも使用する。

## 4. Backend Container

Backend ContainerではSpring BootのDatasource設定を環境変数として渡す。

| 環境変数 | 設定内容 |
|---|---|
| SPRING_DATASOURCE_URL | OracleへのJDBC接続先 |
| SPRING_DATASOURCE_USERNAME | Databaseユーザー名 |
| SPRING_DATASOURCE_PASSWORD | Databaseパスワード |

Docker環境では以下の値を使用する。

```yaml
environment:
  SPRING_DATASOURCE_URL: jdbc:oracle:thin:@//oracle:1521/FREEPDB1
  SPRING_DATASOURCE_USERNAME: ${DB_USERNAME}
  SPRING_DATASOURCE_PASSWORD: ${DB_PASSWORD}
```

Container間通信ではOracle Service名の`oracle`をホスト名として利用する。

```text
jdbc:oracle:thin:@//oracle:1521/FREEPDB1
```

## 5. Spring Boot設定

通常の`application.yml`ではApplication名のみを定義する。

```yaml
spring:
  application:
    name: novel-archive
```

Docker実行時のDatasource情報はDocker Composeから環境変数として設定する。

```text
compose.yml
   ↓
SPRING_DATASOURCE_URL
SPRING_DATASOURCE_USERNAME
SPRING_DATASOURCE_PASSWORD
   ↓
Spring Boot
   ↓
DataSource
```

これにより、Docker用のDatabaseパスワードをSpring Bootの設定ファイルへ直接記載しない構成とする。

## 6. Local Profile

Dockerを使用せずBackendをローカルから直接起動する場合は`application-local.yml`を使用する。

接続先はローカル環境のOracleとする。

```text
jdbc:oracle:thin:@//localhost:1521/FREEPDB1
```

Docker環境との接続先の違いは以下とする。

| 実行環境 | Oracle Host |
|---|---|
| Docker Container内 | oracle |
| Host PCから直接接続 | localhost |

Docker Container内では`localhost`はBackend Container自身を示すため、Oracleへの接続にはService名`oracle`を使用する。

## 7. Git管理

環境ごとに異なる値やパスワードをRepositoryへ登録しないため、`.env`を`.gitignore`の対象とする。

```gitignore
# Docker local environment
.env
```

Repositoryには値の設定方法を示す`.env.example`のみを登録する。

```text
Repository
├─ .env.example    Git管理する
└─ .env            Git管理しない
```

新しい環境では`.env.example`をコピーして`.env`を作成し、必要な値を設定してからDocker Composeを起動する。
