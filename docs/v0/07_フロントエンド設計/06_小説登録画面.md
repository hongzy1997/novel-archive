# 小説登録画面

## 画面概要

新しい小説を登録する画面。

主な機能：

- 小説情報の入力
- 入力値チェック
- 小説登録APIの実行
- 小説一覧画面への遷移
- 日本語 / 中文切替

画面ID：

```text
F003
```

URL：

```text
/novels/new
```

## 入力項目

| 項目 | 入力形式 | API項目 | 必須 | 内容 |
|---|---|---|---|---|
| タイトル | Text | `title` | ○ | 小説タイトル |
| 作者 | Text | `author` | ○ | 著者名 |
| 読書状態 | Select | `readingStatus` | ○ | 0～3から選択 |
| 評価 | Star Rating | `rating` | ○ | 0.5刻みの5段階評価 |
| メモ | Textarea | `memo` | - | 任意のメモ |

---

## 初期値

画面初期表示時の値は以下とする。

| 項目 | 初期値 |
|---|---|
| タイトル | 空 |
| 作者 | 空 |
| 読書状態 | 未読（0） |
| 評価 | 未選択（0星表示） |
| メモ | 空 |

読書状態は必須項目とし、
新規登録時の初期値として `未読（0）` を設定する。

評価は必須項目だが初期値は設定せず、
ユーザーが評価を選択する必要がある。

---

## タイトル

タイトルをText形式で入力する。

必須項目とし、未入力の場合はエラーとして扱う。

```text
タイトルは必須です。
```

---

## 作者

作者をText形式で入力する。

必須項目とし、未入力の場合はエラーとして扱う。

```text
作者は必須です。
```

---

## 読書状態

Select形式で選択する。

初期値は `未読（0）` とする。

| API値 | 日本語 | 中文 |
|---:|---|---|
| 0 | 未読 | 未读 |
| 1 | 読書中 | 阅读中 |
| 2 | 読了 | 已读 |
| 3 | 中断 | 中断 |

画面上の表示文言とAPI値を対応させる。

```text
画面
読了
 ↓
readingStatus = 2
 ↓
API
```

APIへは `0～3` の数値を送信する。

---

## 評価

評価は必須項目とする。

画面では5個の星を表示し、
0.5刻みで評価を選択する。

初期表示：

```text
☆☆☆☆☆
```

初期状態の0星は「評価未選択」を表す画面上の状態であり、
APIへ送信する評価値 `0` を意味しない。

ユーザーが選択できる評価：

```text
0.5 ～ 5.0
```

APIでは `1～10` の整数として送信する。

```text
画面       API

0.5  →     1
1.0  →     2
1.5  →     3
...
4.5  →     9
5.0  →    10
```

変換：

```text
rating = 選択した星数 × 2
```

例：

```text
★★★★½
   ↓
4.5
   ↓
rating = 9
```

評価が未選択の状態で登録した場合は、
Validation Errorとする。

```text
評価を選択してください。
```

---

## メモ

メモはTextarea形式で入力する。

任意入力とし、
未入力でも登録可能とする。

---

## 入力値チェック

登録ボタン押下時、
Frontendで入力値チェックを行う。

| 項目 | チェック内容 |
|---|---|
| タイトル | 必須 |
| 作者 | 必須 |
| 読書状態 | 必須、0～3 |
| 評価 | 必須、1～10 |
| メモ | 任意 |

入力エラーが存在する場合はAPIを呼び出さず、
対象項目付近にエラーメッセージを表示する。

例：

```text
タイトル
[________________]

タイトルは必須です。
```

評価未選択：

```text
評価
☆ ☆ ☆ ☆ ☆

評価を選択してください。
```

Frontendで入力値を確認した後、
Backend側でもValidationを行う。

```text
Frontend Validation
        ↓
POST API
        ↓
Backend Validation
        ↓
登録処理
```

---

## 登録処理

入力値チェックで問題がない場合、
入力内容からRequestを作成する。

例：

```json
{
  "title": "全職高手",
  "author": "蝴蝶藍",
  "readingStatus": 2,
  "rating": 10,
  "memo": "三刷予定"
}
```

登録API：

```text
POST /api/novels
```

処理フロー：

```text
登録ボタン
    ↓
Frontend Validation
    ↓
Request作成
    ↓
POST API
    ↓
Backend Validation
    ↓
DB登録
    ↓
登録成功
    ↓
小説詳細画面
```

登録成功後、
登録された小説の `novelId` を使用して詳細画面へ遷移する。

```text
/novels/{novelId}
```

---

## キャンセル

キャンセルボタン押下時は登録処理を行わず、
小説一覧画面へ遷移する。

```text
キャンセル
    ↓
/novels
```

## 画面状態

### 通常

入力可能な状態。

### 登録中

登録API実行中は登録ボタンを無効化し、
二重登録を防止する。

```text
登録
 ↓
API通信中
 ↓
登録ボタン無効化
 ↓
登録完了
```

### Validation Error

入力内容に問題がある場合、
対象項目付近にエラーメッセージを表示する。

入力内容は保持する。

### API Error

登録処理に失敗した場合：

```text
小説の登録に失敗しました。
```

入力済みの内容は保持し、
ユーザーが修正または再実行できるようにする。

## 言語切替

固定文言は日本語 / 中文の切替に対応する。

| 日本語 | 中文 |
|---|---|
| 小説登録 | 新增小说 |
| タイトル | 标题 |
| 作者 | 作者 |
| 読書状態 | 阅读状态 |
| 評価 | 评分 |
| メモ | 备注 |
| 未読 | 未读 |
| 読書中 | 阅读中 |
| 読了 | 已读 |
| 中断 | 中断 |
| 登録 | 新增 |
| キャンセル | 取消 |

入力したタイトル、作者、メモ、
選択した読書状態・評価は、
言語を切り替えても変更しない。

---

## ポイント

- 入力項目は既存の登録API仕様に合わせる
- タイトル、作者、読書状態、評価を必須とする
- 読書状態の初期値は `未読（0）` とする
- 評価は初期状態を0星（未選択）とする
- 評価未選択の場合は登録できない
- 評価は画面上で0.5刻み、APIでは `1～10` とする
- Frontend Validationでエラーがある場合はAPIを呼び出さない
- API通信中は登録の二重実行を防止する
- 登録失敗時は入力内容を保持する
- 登録成功後は登録した小説の詳細画面へ遷移する
