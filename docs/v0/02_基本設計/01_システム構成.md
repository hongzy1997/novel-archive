## 1. システム全体構成

Novel Archiveは、Frontend、Backend、Databaseで構成する。

```text
Browser
   │
   ▼
Frontend
React + nginx
   │
   │ REST API
   ▼
Backend
Spring Boot
   │
   │ Doma
   ▼
Database
Oracle Database
```

## 2. Frontend

FrontendはReactを利用して画面を構築する。

主な役割は以下とする。

- 小説情報の表示
- ユーザー操作の受付
- 入力内容の管理
- Backend APIとの通信
- 画面切替

## 3. Backend

BackendはSpring Bootを利用してREST APIを提供する。

主な役割は以下とする。

- Frontendからのリクエスト受付
- 入力値チェック
- 小説情報の取得・登録・更新・削除
- Databaseへのアクセス
- エラー処理

## 4. Database

DatabaseにはOracle Databaseを利用する。

小説情報を永続化し、BackendからDomaを経由してアクセスする。

## 5. 処理の流れ

基本的な処理の流れは以下とする。

```text
ユーザー操作
   ↓
React
   ↓ HTTP Request
Spring Boot
   ↓
Service
   ↓
DAO / Doma
   ↓
Oracle Database
   ↓
DAO / Doma
   ↓
Service
   ↓
Spring Boot
   ↓ HTTP Response
React
   ↓
画面表示
```
