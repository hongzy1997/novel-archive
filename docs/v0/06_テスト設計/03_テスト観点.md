## 概要

本書では、テスト時に確認する観点について説明する。

---

# テスト観点

| 観点 | 内容 |
|------|------|
| 正常系 | 正しい入力で正常終了すること |
| 異常系 | 不正入力でエラーとなること |
| 境界値 | 最大値・最小値を確認すること |
| Validation | 入力チェックが動作すること |
| DB整合性 | データが正しく更新されること |
