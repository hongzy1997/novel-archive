## 1. コンポーネント構成

画面固有の処理はPage Componentで管理し、再利用可能なUI部品は`components`配下に配置する。

現在の共通Componentは以下とする。

| Component | 主な利用箇所 | 役割 |
|---|---|---|
| Header | 全画面 | ヘッダー表示、表示言語切替 |
| Footer | 全画面 | フッター表示 |
| NovelCard | 小説一覧画面 | 小説1件分の情報表示 |
| NovelForm | 小説登録・更新画面 | 小説入力フォーム |
| StarRating | 一覧・詳細・登録・更新 | 評価の表示・入力 |

## 2. Header

### 2.1 役割

アプリケーション共通のヘッダーを表示する。

主な機能は以下とする。

- システム名の表示
- 表示言語の切替

### 2.2 データ受け渡し

`App`で管理している表示言語をpropsとして受け取る。

言語切替操作が行われた場合は、親Componentへ変更内容を通知する。

```text
App
 │
 │ language
 │ setLanguage
 ↓
Header
```

## 3. Footer

### 3.1 役割

アプリケーション共通のフッターを表示する。

Footer自身では画面状態やAPI通信を管理しない。

## 4. NovelCard

### 4.1 役割

小説一覧画面で、小説1件分の情報をカード形式で表示する。

主な表示内容は以下とする。

- タイトル
- 作者
- 読書状態
- 評価

### 4.2 データ受け渡し

`NovelListPage`から小説情報を受け取り表示する。

```text
NovelListPage
      │
      │ novelId / title / author
      │ rating / readingStatus / language
      ↓
   NovelCard
```

カードを選択した場合は、対象小説の詳細画面へ遷移する。

### 4.3 評価表示

評価表示には`StarRating`を利用する。

```text
NovelCard
   ↓
StarRating
```

## 5. NovelForm

### 5.1 役割

小説登録画面と小説更新画面で共通利用する入力フォームとする。

以下の入力項目を表示する。

| 項目 | 入力方法 |
|---|---|
| タイトル | テキスト入力 |
| 作者 | テキスト入力 |
| 読書状態 | 選択 |
| 評価 | StarRating |
| メモ | テキスト入力 |

### 5.2 利用画面

```text
NovelCreatePage
      ↓
   NovelForm

NovelEditPage
      ↓
   NovelForm
```

登録・更新そのものは`NovelForm`では行わず、親Pageが実行する。

`NovelForm`は主に以下を担当する。

- 入力項目の表示
- 入力値変更の受付
- Validationエラーの表示
- 評価入力の制御

Page Componentは以下を担当する。

- 入力値の状態管理
- Frontend Validation
- Backend APIの呼び出し
- APIエラーの管理
- 登録・更新完了後の画面遷移

## 6. 読書状態と評価の連動

`NovelForm`では読書状態に応じて評価入力を制御する。

```text
未読
 ↓
評価入力不可
 ↓
rating = null

未読以外
 ↓
評価入力可能
```

読書状態を未読へ変更した場合は、それまで設定されていた評価をクリアする。

この処理により、FrontendでもBackendと同じ入力条件を維持する。

## 7. StarRating

### 7.1 役割

評価を星形式で扱う共通Componentとする。

利用方法によって以下の2種類の動作を行う。

```text
表示用
→ 現在の評価を星で表示

入力用
→ ユーザーが評価を選択
```

### 7.2 利用箇所

| 利用箇所 | 用途 |
|---|---|
| NovelCard | 評価表示 |
| NovelDetailPage | 評価表示 |
| NovelForm | 評価入力 |

これにより、評価表示・入力のUIを各画面で個別実装しない構成とする。

## 8. PageとComponentの関係

Frontend全体の主なComponent関係は以下とする。

```text
App
├─ Header
├─ NovelListPage
│  └─ NovelCard
│     └─ StarRating
├─ NovelDetailPage
│  └─ StarRating
├─ NovelCreatePage
│  └─ NovelForm
│     └─ StarRating
├─ NovelEditPage
│  └─ NovelForm
│     └─ StarRating
└─ Footer
```

## 9. 責務分離

Page Componentと共通Componentは以下のように責務を分離する。

```text
Page Component
= 画面固有の処理
  状態管理
  API通信
  画面遷移

Common Component
= UI表示
  入力操作
  再利用可能な画面部品
```

API通信などの画面固有処理はPage Componentで管理し、共通Componentは表示・入力などのUI処理を中心に担当する。
