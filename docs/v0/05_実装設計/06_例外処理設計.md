# 06_例外処理設計

## 概要

本書では、本システムにおける例外処理方針について説明する。

---

# 役割

例外を一元的に管理し、システム全体で統一したエラーハンドリングを行う。

---

# 実装方針

業務エラーとシステムエラーを分類し、共通の例外ハンドラーで処理する。

---

# 使用する技術

| 技術 | 用途 |
|------|------|
| Spring Exception Handling | 例外処理 |
| @RestControllerAdvice | 共通例外処理 |
| SLF4J | エラーログ出力 |

---

# 実装ルール

- 共通例外ハンドラーを利用する。
- エラーレスポンスを統一する。
- エラーログを出力する。
- 利用者へ内部情報を表示しない。

---

# 実装例

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

}
```

---

# 設計理由

- 例外処理を共通化し、保守性を向上させる。
- エラーレスポンスを統一し、API品質を維持する。
