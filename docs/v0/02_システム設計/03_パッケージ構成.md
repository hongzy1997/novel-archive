## パッケージ一覧

```text
com.hongzy.novelarchive

├── controller
├── dao
├── entity
├── exception
├── dto
└── service
```

---

## パッケージ説明

| パッケージ      | 概要                    |
| ---------- | --------------------- |
| controller | REST API              |
| dao        | データベースアクセス            |
| entity     | データベーステーブルに対応するエンティティ |
| exception  | 例外処理                  |
| dto        | APIのリクエスト・レスポンス       |
| service    | 業務処理                  |

---

## パッケージ依存

```text
controller
      │
      ▼
service
      │
      ▼
dao
      │
      ▼
entity
```

---

## 設計方針

パッケージは役割ごとに分類し、
責務を明確に分離する。

---

## 設計理由

役割単位でパッケージを構成することで、
クラス数が増えても保守しやすく、
見通しの良い構成を維持できる。
