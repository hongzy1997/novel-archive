# フロントエンド共通仕様

## 目的

Novel Archive V0のフロントエンドにおける共通仕様を定義する。

画面ごとの詳細仕様は、各画面設計で定義する。

---

## 使用技術

| 分類 | 内容 |
|---|---|
| フロントエンド | React |
| 言語 | JavaScript |
| 開発・ビルド | Vite |
| API通信 | Fetch API |
| Routing | React Router |
| CSS | 通常のCSS |
| Backend | Spring Boot REST API |

---

## 画面言語

画面表示は以下の2言語に対応する。

```text
日本語
中文
```

言語切替によって変更する対象は、
画面タイトル、ラベル、ボタン、メッセージなどの固定文言とする。

例：

| 日本語 | 中文 |
|---|---|
| 小説一覧 | 小说列表 |
| 小説名を検索 | 搜索小说名 |
| 未読 | 未读 |
| 読書中 | 阅读中 |
| 読了 | 已读 |
| 中断 | 中断 |

小説タイトル、著者、メモなどBackendから取得する業務データは、
言語切替の対象外とする。

```text
UI固定文言
→ 言語切替対象

API取得データ
→ そのまま表示
```

---

## Routing

画面遷移はReact Routerを利用する。

想定URL：

```text
/novels
→ 小説一覧

/novels/new
→ 小説登録

/novels/:novelId
→ 小説詳細

/novels/:novelId/edit
→ 小説更新
```

URLと表示するComponentを対応付ける。

詳細な画面遷移は `03_画面遷移` で定義する。

---

## API通信

FrontendとBackendはREST API / HTTPで連携する。

```text
React
  ↓ HTTP Request
Spring Boot
  ↓
Doma
  ↓
Oracle Database
```

Response：

```text
Oracle Database
  ↓
Spring Boot
  ↓ JSON
React
  ↓
UI
```

API仕様は `04_API設計` の内容を使用する。

Frontend側では既存API仕様に合わせてRequest / Responseを扱う。

---

## 一覧検索

V0では小説一覧取得APIで全件取得し、
Frontend側でタイトル検索を行う。

```text
GET /api/novels
    ↓
全件取得
    ↓
React State
    ↓
filter()
    ↓
検索結果表示
```

検索対象：

```text
小説タイトル
```

部分一致検索とする。

V0ではFrontend側でタイトル部分一致検索を行う。

## 読書状態

Backendでは以下の値を使用する。

| 値 | 日本語 | 中文 |
|---:|---|---|
| 0 | 未読 | 未读 |
| 1 | 読書中 | 阅读中 |
| 2 | 読了 | 已读 |
| 3 | 中断 | 中断 |

FrontendではAPI値を表示文言へ変換する。

```text
readingStatus = 0
→ 未読 / 未读

readingStatus = 1
→ 読書中 / 阅读中
```

登録・更新画面ではSelect形式で選択する想定とする。

APIへ送信する値は `0～3` の数値とする。

---

## 評価

Backend / APIでは評価を `1～10` で管理する。

Frontendでは5段階の星表示とし、
0.5刻みで表現する。

```text
API     UI

1   →   0.5
2   →   1.0
3   →   1.5
4   →   2.0
...
9   →   4.5
10  →   5.0
```

変換：

```text
表示星数 = rating / 2
```

登録・更新時：

```text
API rating = 選択した星数 × 2
```

一覧・詳細画面では表示用、
登録・更新画面では選択可能なUIとして実装する。

---

## 画面状態

API通信を行う画面では、
必要に応じて以下の状態を管理する。

```text
Loading
Error
Empty
Success
```

例：

```text
API取得中
→ 読込中表示

API取得失敗
→ エラー表示

0件
→ データなし表示

正常取得
→ データ表示
```

具体的な表示方法は各画面設計で定義する。

---

## Component設計

画面はComponent単位で分割して実装する。

基本イメージ：

```text
App
├── Header
├── LanguageSwitcher
├── 各画面Component
└── 共通Component
```

小説表示など複数画面で利用するUIは、
必要に応じて共通Component化する。

例：

```text
NovelCard
RatingStars
```

詳細なComponent構成は別途定義する。


---

## ポイント

- FrontendはReactで実装する
- 画面は日本語 / 中文に対応する
- RoutingはReact Routerを利用する
- V0の検索はFrontend側で行う
- 読書状態はAPI値 `0～3` を表示文言へ変換する
- 評価はAPI `1～10`、UIは0.5刻みの5段階星表示とする
- API仕様は既存のBackend設計を使用する
- PaginationおよびBackend検索はV1で対応する
