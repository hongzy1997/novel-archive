## 1. プロジェクト名

Novel Archive


## 2. 概要

Novel Archiveは、読んだ小説の情報を記録・管理するための個人開発Webアプリケーションである。

小説のタイトル、作者、読書状態、評価、メモなどを管理し、
自身の読書履歴を整理・参照できることを目的とする。

また、本プロジェクトではWebアプリケーション開発における
要件定義、設計、実装、テスト、実行環境構築までの一連の開発工程を実践する。


## 3. V0の目的

V0では、Novel Archiveの基本機能および実行環境を構築する。

主な目的は以下とする。

- 小説管理CRUD機能の実装
- ReactによるFrontendの実装
- Spring BootによるREST APIの実装
- Oracle Databaseによるデータ管理
- FrontendとBackendのAPI連携
- Dockerによる実行環境の構築
- Docker ComposeによるFrontend、Backend、Databaseの一括起動
- 設計、実装、テストを含む開発工程の実践


## 4. V0の構成

V0では、以下の構成でWebアプリケーションを構築する。

- Frontend：React
- Backend：Spring Boot
- Database：Oracle Database
- Data Access：Doma
- Web Server：nginx
- Execution Environment：Docker / Docker Compose
- Version Control：Git / GitHub


## 5. V0の完成状態

V0では、以下を実現した。

- 小説情報の登録・参照・更新・削除
- 読書状態、評価、メモの管理
- ReactとSpring Boot REST APIの連携
- Oracle Databaseへのデータ保存・取得
- Dockerによる各実行環境のコンテナ化
- Docker Composeによるシステム全体の起動
- Oracle Databaseの初期化自動化
- Docker Volumeによるデータ永続化
- nginxによるFrontend配信およびBackend APIへのリバースプロキシ
