## 1. ER図

現在のシステムでは、業務データを管理するテーブルは`NOVELS`のみとする。

```text
┌──────────────────────────────┐
│            NOVELS            │
├──────────────────────────────┤
│ PK  NOVEL_ID                 │
│ UQ  TITLE                    │
│     AUTHOR                   │
│     READING_STATUS           │
│     RATING                   │
│     MEMO                     │
│     CREATED_AT               │
│     UPDATED_AT               │
└──────────────────────────────┘
```

## 2. リレーション

現在は`NOVELS`以外の業務テーブルを使用しないため、テーブル間のリレーションは存在しない。

```text
NOVELS
```

## 3. 関連DBオブジェクト

`NOVELS`テーブルでは以下のDBオブジェクトを使用する。

```text
NOVEL_SEQ
    │
    └─ NOVEL_ID採番
           ↓
        NOVELS
           ↑
    UPDATED_AT更新
           │
TRG_NOVELS_UPDATED_AT
```

`NOVEL_SEQ`および`TRG_NOVELS_UPDATED_AT`はテーブル間リレーションではないため、ER図上のEntityとしては扱わない。
