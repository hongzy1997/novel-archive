# 画面遷移

## 画面遷移概要

Novel Archive V0では、React Routerを利用して画面遷移を行う。

画面とURLの対応は以下とする。

| 画面ID | 画面名 | URL |
|---|---|---|
| F001 | 小説一覧画面 | `/novels` |
| F002 | 小説詳細画面 | `/novels/:novelId` |
| F003 | 小説登録画面 | `/novels/new` |
| F004 | 小説更新画面 | `/novels/:novelId/edit` |

`:novelId` には対象小説のIDを指定する。

例：

```text
/novels/1
→ novelId = 1 の小説詳細

/novels/1/edit
→ novelId = 1 の小説更新
```

## 画面遷移図

```text
                 ┌───────────────┐
                 │ F003 小説登録 │
                 └───────┬───────┘
                         │
                    登録成功
                         │
                         ▼
┌───────────────┐   ┌───────────────┐
│ F001 小説一覧 │ → │ F002 小説詳細 │
└───────┬───────┘   └───────┬───────┘
        │                    │
        │ 新規登録           │ 更新
        │                    ▼
        │            ┌───────────────┐
        └──────────→ │ F004 小説更新 │
                     └───────┬───────┘
                             │
                         更新成功
                             │
                             ▼
                     ┌───────────────┐
                     │ F002 小説詳細 │
                     └───────────────┘
```

※ F001からF004へ直接遷移するのではなく、
F004はF002から遷移する。

---

## F001 小説一覧画面

### 小説詳細

一覧から小説を選択する。

```text
F001 小説一覧
    ↓ 小説選択
F002 小説詳細
```

遷移先：

```text
/novels/{novelId}
```

### 新規登録

新規登録ボタンを選択する。

```text
F001 小説一覧
    ↓ 新規登録
F003 小説登録
```

遷移先：

```text
/novels/new
```

---

## F002 小説詳細画面

### 更新

更新ボタンを選択する。

```text
F002 小説詳細
    ↓ 更新
F004 小説更新
```

遷移先：

```text
/novels/{novelId}/edit
```

### 戻る

戻る操作で小説一覧画面へ遷移する。

```text
F002 小説詳細
    ↓ 戻る
F001 小説一覧
```

遷移先：

```text
/novels
```

### 削除

削除ボタン押下後、確認を行う。

```text
F002 小説詳細
    ↓
削除
    ↓
確認
    ↓
DELETE API
    ↓
削除成功
    ↓
F001 小説一覧
```

削除をキャンセルした場合は画面遷移しない。

---

## F003 小説登録画面

登録成功後、登録した小説の詳細画面へ遷移する。

```text
F003 小説登録
    ↓
登録
    ↓
POST API
    ↓
登録成功
    ↓
F002 小説詳細
```

遷移先：

```text
/novels/{novelId}
```

キャンセル時は小説一覧画面へ戻る。

---

## F004 小説更新画面

更新成功後、対象小説の詳細画面へ遷移する。

```text
F004 小説更新
    ↓
更新
    ↓
PUT API
    ↓
更新成功
    ↓
F002 小説詳細
```

遷移先：

```text
/novels/{novelId}
```

キャンセル時は対象小説の詳細画面へ戻る。

---

## React Routerとの関係

画面遷移はReact Routerで管理する。

```text
URL
 ↓
React Router
 ↓
対応する画面Component
```

例：

```text
/novels
→ NovelList

/novels/1
→ NovelDetail

/novels/new
→ NovelCreate

/novels/1/edit
→ NovelEdit
```

Component名などの実装詳細はComponent設計で定義する。
