# 小説詳細画面

## 画面概要

選択した小説の詳細情報を表示する画面。

主な機能：

- 小説詳細情報の表示
- 小説更新画面への遷移
- 小説削除
- 小説一覧画面への遷移
- 日本語 / 中文切替

画面ID：

```text
F002
```

URL：

```text
/novels/:novelId
```

---

## 画面イメージ

```text
┌──────────────────────────────────────────────┐
│ Novel Archive                  [日本語 | 中文] │
│ 小説管理システム                             │
└──────────────────────────────────────────────┘


小説詳細

タイトル：全職高手

作者：蝴蝶藍

読書状態：読了

評価：★★★★★

メモ：
三刷予定


[一覧へ戻る]              [更新]  [削除]
```

---

## 表示項目

| 項目 | 内容 |
|---|---|
| タイトル | 小説タイトル |
| 著者 | 著者名 |
| 読書状態 | 未読 / 読書中 / 読了 / 中断 |
| 評価 | 5段階星表示（0.5刻み） |
| メモ | 登録されているメモ |
| 一覧へ戻るボタン | 小説一覧画面へ遷移 |
| 更新ボタン | 小説更新画面へ遷移 |
| 削除ボタン | 対象小説を削除 |

---

## 詳細データ取得

URLから `novelId` を取得し、
小説詳細取得APIを呼び出す。

例：

```text
URL
/novels/1

    ↓

novelId = 1

    ↓

小説詳細取得API

    ↓

対象小説を表示
```

使用API：

```text
GET /api/novels/{novelId}
```

取得項目：

```text
novelId
title
author
readingStatus
rating
memo
```

---

## 評価表示

APIの `rating` を5段階の星へ変換して表示する。

```text
rating = 10
→ ★★★★★

rating = 9
→ 4.5星

rating = 7
→ 3.5星
```

詳細画面では参照のみとし、
評価の変更は更新画面で行う。

---

## 読書状態表示

`readingStatus` を表示文言へ変換する。

| 値 | 日本語 | 中文 |
|---:|---|---|
| 0 | 未読 | 未读 |
| 1 | 読書中 | 阅读中 |
| 2 | 読了 | 已读 |
| 3 | 中断 | 中断 |

---

## 更新

更新ボタン押下時、
対象小説の更新画面へ遷移する。

```text
更新
  ↓
novelId
  ↓
/novels/{novelId}/edit
  ↓
F004 小説更新画面
```

例：

```text
novelId = 1

→ /novels/1/edit
```

---

## 削除

削除ボタン押下時、
削除確認を表示する。

例：

```text
この小説を削除しますか？

[キャンセル] [削除]
```

削除を確定した場合、
対象小説の削除APIを呼び出す。

```text
削除ボタン
    ↓
削除確認
    ↓
DELETE /api/novels/{novelId}
    ↓
削除成功
    ↓
小説一覧画面
```

削除成功後：

```text
/novels
```

へ遷移する。

キャンセルした場合は削除せず、
詳細画面をそのまま表示する。

---

## 一覧へ戻る

一覧へ戻るボタン押下時：

```text
F002 小説詳細
    ↓
一覧へ戻る
    ↓
F001 小説一覧
```

遷移先：

```text
/novels
```

---

## 画面状態

### Loading

詳細データ取得中：

```text
読込中...
```

### Not Found

指定された小説が存在しない場合：

```text
小説が見つかりません。
```

### Error

詳細データ取得に失敗した場合：

```text
小説情報の取得に失敗しました。
```

### 削除Error

削除処理に失敗した場合：

```text
小説の削除に失敗しました。
```

## 言語切替

固定文言は日本語 / 中文の切替に対応する。

例：

| 日本語 | 中文 |
|---|---|
| 小説詳細 | 小说详情 |
| タイトル | 标题 |
| 作者 | 作者 |
| 読書状態 | 阅读状态 |
| 評価 | 评分 |
| メモ | 备注 |
| 一覧へ戻る | 返回列表 |
| 更新 | 编辑 |
| 削除 | 删除 |
| キャンセル | 取消 |

小説タイトル、著者、メモなど、
APIから取得したデータは言語切替の対象外とする。

---

## ポイント

- URLの `novelId` を利用して詳細データを取得する
- 詳細画面では全項目を表示する
- 評価と読書状態はFrontend側で表示形式を変換する
- 更新ボタンから対象小説の更新画面へ遷移する
- 削除前に確認を行う
- 削除成功後は小説一覧画面へ遷移する
- 存在しないIDとAPI通信エラーを区別する
