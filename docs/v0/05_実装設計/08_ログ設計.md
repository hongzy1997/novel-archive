# 08_ログ設計

## 概要

本書では、本システムにおけるログ出力方針について説明する。

---

# 役割

システムの動作状況を記録し、障害解析および運用監視を支援する。

---

# 実装方針

ログは必要最小限とし、障害調査に必要な情報のみを出力する。

---

# 使用する技術

| 技術 | 用途 |
|------|------|
| SLF4J | ログ出力 |
| Logback | ログ管理 |

---

# 実装ルール

- INFO、WARN、ERRORを適切に使い分ける。
- エラー時はExceptionを出力する。
- 個人情報および機密情報は出力しない。
- デバッグ用途のログは本番へ残さない。

---

# 実装例

```java
private static final Logger log =
        LoggerFactory.getLogger(NovelService.class);

log.info("Create Novel start.");

log.error("Create Novel failed.", e);
```

---

# 設計理由

- 障害調査を容易にする。
- 不要なログを削減し、可読性を維持する。
- セキュリティを考慮したログ運用を行う。
