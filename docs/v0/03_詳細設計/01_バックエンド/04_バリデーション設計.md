## 1. バリデーション概要

小説登録・更新APIでは、`NovelRequest`に対してBean Validationを実行する。

入力項目単体のチェックには標準Validationアノテーションを使用する。

読書状態と評価の組み合わせチェックには、独自Validationである`ValidRating`を使用する。

```text
NovelRequest
   ├─ 標準Validation
   │   ├─ @NotBlank
   │   ├─ @NotNull
   │   ├─ @Size
   │   ├─ @Min
   │   └─ @Max
   │
   └─ @ValidRating
         ↓
      RatingValidator
```

## 2. 項目別Validation

| 項目 | Validation | 条件 | エラーメッセージ |
|---|---|---|---|
| title | `@NotBlank` | null、空文字、空白のみを不可とする | タイトルは必須です。 |
| title | `@Size(max = 200)` | 200文字以内 | タイトルは200文字以内で入力してください。 |
| author | `@Size(max = 100)` | 100文字以内 | 作者は100文字以内で入力してください。 |
| readingStatus | `@NotNull` | null不可 | 読書状態は必須です。 |
| readingStatus | `@Min(0)` | 0以上 | 読書状態が不正です。 |
| readingStatus | `@Max(3)` | 3以下 | 読書状態が不正です。 |
| rating | `@Min(1)` | 値がある場合は1以上 | 評価は1～10で入力してください。 |
| rating | `@Max(10)` | 値がある場合は10以下 | 評価は1～10で入力してください。 |
| memo | `@Size(max = 1000)` | 1000文字以内 | メモは1000文字以内で入力してください。 |

`author`、`rating`、`memo`はnullを許可する。

## 3. 読書状態

`readingStatus`は以下の値を使用する。

| 値 | 状態 |
|---|---|
| 0 | 未読 |
| 1 | 読書中 |
| 2 | 読了 |
| 3 | 中断 |

0～3以外の値はValidationエラーとする。

## 4. 評価Validation

評価は`readingStatus`との組み合わせによって入力条件が変わるため、項目単体のValidationだけではなく`ValidRating`によるクラス単位のValidationを行う。

組み合わせは以下とする。

| readingStatus | rating | 判定 |
|---|---|---|
| 0：未読 | null | OK |
| 0：未読 | 値あり | NG |
| 1：読書中 | 値あり | OK |
| 1：読書中 | null | NG |
| 2：読了 | 値あり | OK |
| 2：読了 | null | NG |
| 3：中断 | 値あり | OK |
| 3：中断 | null | NG |

エラー時は以下のメッセージを返却する。

```text
未読の場合は評価できません。未読以外の場合は評価が必須です。
```

## 5. ValidRating

`ValidRating`は`NovelRequest`に付与する独自Validationアノテーションとする。

```java
@ValidRating
public class NovelRequest {
    ...
}
```

Validation処理は`RatingValidator`で実行する。

## 6. RatingValidator

`RatingValidator`では`readingStatus`と`rating`の組み合わせを判定する。

基本的な判定は以下とする。

```text
readingStatus = 0
    → rating == null

readingStatus != 0
    → rating != null
```

`readingStatus`がnullの場合は、必須チェックを`@NotNull`に任せるため、`RatingValidator`ではエラーとしない。

## 7. エラー項目

`ValidRating`はクラス単位のValidationであるが、エラーは`NovelRequest`全体ではなく`rating`項目のエラーとして設定する。

```text
NovelRequest
   ↓
@ValidRating
   ↓
RatingValidator
   ↓
ratingフィールドのエラーとして返却
```

これにより、Validationエラーレスポンスでは`rating`項目のエラーとして返却される。

## 8. Validation実行タイミング

登録・更新APIでRequest Bodyを受け取る際にValidationを実行する。

```text
HTTP Request
   ↓
NovelRequest
   ↓
Bean Validation
   ├─ 項目Validation
   └─ ValidRating
   ↓
正常
   ↓
NovelService
```

Validationエラーが存在する場合はService処理を実行せず、400 Bad Requestを返却する。
