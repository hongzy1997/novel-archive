## 1. 小説一覧画面

### 1.1 概要

登録されている小説を一覧表示する。

画面上部ではタイトルによる絞り込みを行うことができる。

### 1.2 表示内容

各小説について以下の情報を表示する。

| 項目 | 内容 |
|---|---|
| タイトル | 小説のタイトル |
| 作者 | 小説の作者 |
| 読書状態 | 未読、読書中、読了、中断 |
| 評価 | 1～10の評価 |

### 1.3 操作

| 操作 | 動作 |
|---|---|
| タイトル検索 | 入力した文字を含むタイトルのみ一覧表示する |
| 小説選択 | 選択した小説の詳細画面へ遷移する |
| 新規登録 | 小説登録画面へ遷移する |

### 1.4 表示状態

- 一覧取得中は読込中メッセージを表示する。
- 一覧取得に失敗した場合はエラーメッセージを表示する。
- 小説が1件も登録されていない場合はデータなしメッセージを表示する。
- 検索条件に一致する小説が存在しない場合は該当データなしメッセージを表示する。

## 2. 小説詳細画面

### 2.1 概要

選択した小説の詳細情報を表示する。

### 2.2 表示内容

| 項目 | 内容 |
|---|---|
| タイトル | 小説のタイトル |
| 作者 | 小説の作者 |
| 読書状態 | 未読、読書中、読了、中断 |
| 評価 | 1～10の評価 |
| メモ | 感想や補足情報 |

作者が未設定の場合は「不明」を表示する。

評価が未設定の場合は「未評価」を表示する。

メモが未設定の場合は「なし」を表示する。

### 2.3 操作

| 操作 | 動作 |
|---|---|
| 一覧へ戻る | 小説一覧画面へ遷移する |
| 更新 | 小説更新画面へ遷移する |
| 削除 | 確認メッセージを表示し、確認後に対象小説を削除する |

削除完了後は小説一覧画面へ遷移する。

---

## 3. 小説登録画面

### 3.1 概要

新しい小説情報を入力して登録する。

### 3.2 入力項目

| 項目 | 入力方法 | 必須 | 制約 |
|---|---|---|---|
| タイトル | テキスト入力 | ○ | 200文字以内 |
| 作者 | テキスト入力 | - | 100文字以内 |
| 読書状態 | 選択 | ○ | 未読、読書中、読了、中断 |
| 評価 | 評価選択 | 条件付き | 1～10 |
| メモ | テキスト入力 | - | 1000文字以内 |

### 3.3 評価入力

読書状態が「未読」の場合は評価を設定できない。

読書状態が「未読」以外の場合は評価を必須とする。

読書状態を「未読」に変更した場合、入力済みの評価はクリアする。

### 3.4 操作

| 操作 | 動作 |
|---|---|
| 一覧へ戻る | 登録せず小説一覧画面へ遷移する |
| クリア | 入力内容を初期状態に戻す |
| 登録 | 入力内容をチェックし、小説を登録する |

登録完了後は、登録した小説の詳細画面へ遷移する。

同一タイトルの小説が既に存在する場合は登録せず、エラーメッセージを表示する。

---

## 4. 小説更新画面

### 4.1 概要

登録済みの小説情報を編集する。

画面表示時に対象小説の現在の情報を取得し、各入力項目の初期値として表示する。

### 4.2 入力項目

入力項目および入力条件は小説登録画面と同様とする。

### 4.3 操作

| 操作 | 動作 |
|---|---|
| 戻る | 更新せず小説詳細画面へ遷移する |
| リセット | 入力内容を更新前の状態に戻す |
| 更新 | 入力内容をチェックし、小説情報を更新する |

更新完了後は対象小説の詳細画面へ遷移する。

他の小説と同一タイトルになる場合は更新せず、エラーメッセージを表示する。

---

## 5. 表示言語

画面表示は以下の2言語に対応する。

- 日本語
- 中国語

ヘッダーから表示言語を切り替えることができる。

言語を切り替えた場合、画面上のラベル、ボタン、メッセージ等を選択した言語で表示する。
