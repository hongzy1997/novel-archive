## 1. プロジェクト名

Novel Archive

## 2. 概要

Novel Archiveは、読んだ小説や気になる小説を管理するためのWebアプリケーションである。

個人開発を通して、Frontend、Backend、Databaseを利用したWebアプリケーション開発の基本構成を学習することを目的とする。

## 3. システム構成

本システムは以下の構成とする。

```text
Browser
   ↓
React
   ↓ REST API
Spring Boot
   ↓ Doma
Oracle Database
```

各アプリケーションおよびDatabaseはDocker上で実行する。

## 4. 主な機能

本システムでは、小説情報に対する基本的な管理機能を提供する。

- 小説一覧表示
- 小説詳細表示
- 小説登録
- 小説編集
- 小説削除

各機能の詳細については要件定義および各設計書で定義する。

## 5. 主な使用技術

| 分類 | 技術 |
|---|---|
| Frontend | React / Vite |
| Backend | Java / Spring Boot |
| Database Access | Doma |
| Database | Oracle Database |
| Build | Gradle |
| Infrastructure | Docker / Docker Compose |
| Version Control | Git / GitHub |
