# 07_入力チェック設計

## 概要

本書では、本システムにおける入力チェックの実装方針について説明する。

---

# 役割

APIへ入力されるデータを検証し、不正なデータの登録を防止する。

---

# 実装方針

入力チェックはRequestクラスで実施し、Spring Validationを利用する。

---

# 使用するアノテーション

| アノテーション | 用途 |
|---------------|------|
| @Valid | Validation実行 |
| @NotNull | 必須 |
| @NotBlank | 空文字チェック |
| @Size | 文字数 |
| @Min | 最小値 |
| @Max | 最大値 |
| @Pattern | 書式チェック |

---

# 実装ルール

- Requestクラスへ定義する。
- Controllerで@Validを利用する。
- Serviceで再チェックしない。

---

# 実装例

```java
public class CreateNovelRequest {

    @NotBlank
    private String title;

    @Size(max = 100)
    private String author;

}
```

---

# 設計理由

- Validationを共通化し、入力チェック漏れを防止する。
- Requestへ集約し、可読性を向上させる。
