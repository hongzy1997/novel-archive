## 1. 画面一覧

| No. | 画面 | 概要 |
|---|---|---|
| 1 | 小説一覧画面 | 登録されている小説を一覧表示する |
| 2 | 小説詳細画面 | 選択した小説の詳細情報を表示する |
| 3 | 小説登録画面 | 新しい小説情報を入力して登録する |
| 4 | 小説編集画面 | 登録済みの小説情報を編集する |

## 2. 画面遷移

基本的な画面遷移は以下とする。

```text
小説一覧画面
   ├─ 小説を選択
   │     ↓
   │  小説詳細画面
   │     ├─ 編集
   │     │    ↓
   │     │  小説編集画面
   │     │    ↓
   │     │  小説詳細画面
   │     │
   │     └─ 削除
   │          ↓
   │       小説一覧画面
   │
   └─ 新規登録
         ↓
      小説登録画面
         ↓
      小説詳細画面
```

## 3. 画面遷移方針

- 小説一覧画面を基本の起点とする。
- 一覧から小説を選択すると、小説詳細画面へ遷移する。
- 新規登録完了後は、登録した小説の詳細画面へ遷移する。
- 編集完了後は、小説詳細画面へ戻る。
- 削除完了後は、小説一覧画面へ戻る。
